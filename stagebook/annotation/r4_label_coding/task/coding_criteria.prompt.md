**Quick reference**

| Category      | Means                                                                                                                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Resemblance   | The label says what the figure looks like as a whole, using a known object or idea (e.g. `horse`, `scooby doo`, `red robot`).                                                                                                |
| Feature based | The label names the figure's parts and their attributes (e.g. `red hat green feet`, `OPB`, `purple hat right yellow feet`).                                                                                                  |
| Arbitrary     | The label has no relation to the figure — pure memorization (e.g. `A`, `B`, `C`, `january`, `xyz`). **Short codes like `RGB` are Feature based if the letters map to image attributes — always check earlier rounds first.** |
| No response   | Empty or whitespace only.                                                                                                                                                                                                    |
| Unknown       | If unsure, pick this and **leave a note below**.                                                                                                                                                                             |
