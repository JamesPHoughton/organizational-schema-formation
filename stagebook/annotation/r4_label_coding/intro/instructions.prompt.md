# Label Classification Task

In another study, we asked people to label sets of images like the one below:

![Example image set](intro/round_3_panel.jpg)

Your task is to classify their labels into one of the following categories:

**One-off Labels:**

Sometimes, people used **one-off labels** that described what each image reminded them of, independent of the others. For example:

| 1. Rainbow  | 2. "T"      | 3. Robot      | 4. Bird     |
| ----------- | ----------- | ------------- | ----------- |
| **5. Mask** | **6. Cube** | **7. Yellow** | **8. Crab** |

**Systematic Labels:**

Other times, people created a **system of labels** based on different parts of the figures (hands, hat, feet, eyes, _etc._). For example:

| 1. Purple hat, black hands, yellow feet  | 2. Purple hat, red hands, brown feet       | 3. Orange hat, black hands, yellow feet    | 4. Purple hat, red hands, yellow feet     |
| ---------------------------------------- | ------------------------------------------ | ------------------------------------------ | ----------------------------------------- |
| **5. Orange hat, red hands, brown feet** | **6. Orange hat, black hands, brown feet** | **7. Purple hat, black hands, brown feet** | **8. Orange hat, red hands, yellow feet** |

or abbreviations of the above. For example:

| 1. PBY     | 2. PRB     | 3. OBY     | 4. PRY     |
| ---------- | ---------- | ---------- | ---------- |
| **5. ORB** | **6. OBB** | **7. PBB** | **8. ORY** |

**Other approaches:**

Sometimes, people used arbitrary labels with no relation to the images ("Mike", "Sarah", "Bob" _etc._; "January", "February", "March" _etc._).

Some labels are missing, or gibberish.

And sometimes, you just can't tell.

In any of these cases, please mark the label as **"Can't tell / Neither"**.

## Practice

Please classify each the following labels as either "One-off", "Systematic", or "Can't tell / Neither".

We've given you the full set for comparison, but we want you to categorize just the indicated label.
