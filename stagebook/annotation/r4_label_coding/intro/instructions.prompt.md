# Classifying labels in a coordination study

In this task we'd like you to help us classify responses from another study, according to the **strategy** each participant used. Each task is one participant: you see four rounds of their labels and decide what kind they typed in Round 4.

## What participants did

Pairs of participants were shown sets of 8 images and had to give each image a unique short name. They discussed over video, then independently typed their labels from memory. Many developed a **personal naming strategy** over four rounds. We want to know which strategy each one used in **Round 4**.

## What you'll see in each task

- This participant's earlier labels (Rounds 1c, 2, 3).
- Their partner's Round 3 labels.
- Eight Round 4 labels to classify.

**Skim all eight Round 4 labels first** — the whole set reveals the strategy faster than any single label.

## The five categories

**Resemblance.** The label says what the figure looks like _as a whole_, by reference to something the participant already knows. Examples: `horse`, `scooby doo`, `red robot`, `the angry one`. _Defining move:_ points outside the image set.

**Feature based.** The label is built from the figure's **parts and their attributes**. Examples: `red hat green feet`, `purple hat right yellow feet`, `OPB`, `P1`. _Defining move:_ decomposes the figure into slots filled with different values across the set.
**Compressed codes count.** `RGB` from someone whose earlier labels were `red hat green hands brown feet` is Feature based. The test isn't how the label looks, it's whether each character maps to a varying attribute.

**Arbitrary.** No connection to the figure or its parts — pure memorization. Examples: `A`, `B`, `C`, `D`; `january`, `february`; `1`, `2`, `3`; `curly`, `moe`, `larry`. _Defining move:_ no way to derive the label by looking at the image. **Always check earlier rounds first** — short codes that map to image attributes can be Feature based, not Arbitrary.

**No response.** Empty / whitespace only. Shown as `∅ (no response)` in the task.

**Unknown.** Typos, single ambiguous characters, gibberish, or genuinely uncertain. When in doubt, pick this and leave a note.

## Tips

- **Judge against this participant's own history.** There is no global answer key - judge each label in context.
- **Compression is normal.** Participants often start long and shorten over rounds — `red hat green feet` → `RGB`.
- **Partners can disagree.** Especially in groups that didn't coordinate. Judge each participant against their _own_ labels, not the partner's.
